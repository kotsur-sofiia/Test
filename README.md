# Мой день

Минимальное PWA: список задач, локальное сохранение, офлайн-режим и установка на главный экран. Без зависимостей и сборки. Данные хранятся только в браузере текущего устройства.

## Запуск

Из корня репозитория: `python3 -m http.server 8000 --bind 127.0.0.1`.

Service Worker работает на HTTPS или localhost. После первого открытия дождитесь активации: затем приложение можно перезагрузить без интернета.

## Публикация

В GitHub: Settings → Pages → Deploy from a branch → ветка `gh-pages` → папка `/ (root)` → Save.

После успешного развёртывания адрес: https://kotsur-sofiia.github.io/Test/

Для обновлений отправляйте проверенную версию в `main` и `gh-pages`. При изменении офлайн-файлов увеличивайте версию `CACHE` в `sw.js`.

Android: «Установить приложение» в меню браузера или кнопка в приложении, когда браузер её предложит. Safari на iPhone: «Поделиться» → «На экран Домой».
